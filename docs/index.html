How the scoring works
PillarHow it's scored (0–100)
ValueNet annual value (time saved × loaded cost + other value − run cost), log-scaled from $25k (0 points) to $5M (70 points), plus 15 for an agreed KPI and 15 for an executive sponsor.
ReadinessData access 25 · usable APIs 25 · documented process 20 · evaluation set 15 · observability 15.
RiskAutonomy (5–35) + irreversibility (0–20) + data sensitivity (0–20) + regulation (0–15) + customer-facing (10). Autonomous and irreversible together is always Critical. Tiers: Low <30 · Medium 30–54 · High 55–75 · Critical ≥76.
VerdictRule (checked in this order)
🔴 StopValue score <25, or Critical risk with readiness <50
🟠 Rework before fundingNo agreed KPI, or readiness <40
🟡 Pilot with guardrailsHigh/Critical risk, readiness <65, or value <50
🟢 Fund to productionEverything else

Controls are tiered by risk, not uniform: a low-risk assistant needs an owner and an inventory entry; a critical autonomous agent needs gateway-enforced tool allow-lists, audit logs, a tested kill switch, red-teaming, staged autonomy and board sign-off. Weights are opinionated defaults — adapt them to your own AI policy. Source code, tests and the Python version: GitHub.
